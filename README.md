# Obsidian — ZeroSpend

Cofre de documentação do **ZeroSpend**: gerenciador e auditor de assinaturas de software para
pequenas e médias empresas (*SaaS Spend Management*). Mostra quanto a empresa gasta com software, acha
ferramentas redundantes e avisa antes de cada renovação.
